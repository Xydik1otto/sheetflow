## [1.0.0] — 2026-11-05

Випуск «готово для чужих користувачів»: сторонній користувач запускає
SheetFlow за 5 хвилин без знання коду.

### Додано
- **Користувацькі поля** на колекцію: `text` / `number` / `date` / `select`
  (select — зі списком варіантів). CRUD ендпоінти (`/api/collections/{id}/fields`),
  значення зберігаються в `rows.extra_json`, валідація типів при inline- і
  масовому редагуванні, пошук охоплює їхні значення, UI-панель «Користувацькі
  поля» з динамічними колонками таблиці.
- **Формули між полями з валідацією циклів**: формули можуть посилатися на
  звичайні *й* користувацькі поля та на інші розрахункові колонки; цикли
  (прямі, самопосилання, довгі) відкидаються з 422 (`calc.detect_cycles`,
  DFS по графу залежностей); колізії імен custom↔calc заборонені.
- **5 шаблонів колекцій** одним кліком: `orders`, `clients`, `inventory`,
  `tasks`, `subscriptions` — з демо-рядками й валідованим мапінгом.
- **Multi-sheet імпорт xlsx**: `importer.list_sheets()`, параметр `sheet` в
  upload/map, селектор аркуша в UI для багатоаркушевих книг.
- **i18n UA/EN**: перемикач у шапці (`app/static/i18n.js` — JSON-словники),
  авто-детект мови браузера (`navigator.language`), збереження вибору в
  localStorage. Без російської локалізації — свідоме рішення.
- **First-run demo**: opt-in кнопка «Завантажити демо-колекцію»
  (`POST /api/demo`) — демо-колекція з користувацькими полями й формулою;
  не дублюється (409).
- **Packaging**: `pyproject.toml` (метадані v1.0.0, dev extra),
  console-script `sheetflow` (`app/cli.py`), `pip install -e .` працює;
  `start.bat` для Windows.
- **INSTALL.md**: покрокова інструкція для не-програміста — Windows
  (start.bat, автозапуск через папку Startup), Linux (systemd user unit),
  оновлення, зміна пароля, типові проблеми.
- **Data safety**: one-click експорт усіх даних в JSON
  (`GET /api/export/json`); видалення колекції (admin) з per-row аудитом і
  підтвердженням «введіть назву» в UI.
- **A11y**: aria-labels на інтерактивних елементах, live-регіони статусу
  (`aria-live`), видимий фокус (`:focus-visible`), Enter у логіні та майстрі
  імпорту, контраст бейджа прострочених підвищено.
- **Open-source hygiene**: `README.en.md`, `CONTRIBUTING.md`, `SECURITY.md`,
  bilingual issue-шаблони (UA/EN), privacy-аудит репозиторію тестом,
  `.gitignore` покриває `.env` і `*.db*`.

### Змінено
- README.md оновлено до v1.0.0 (укр) + додано англійську версію.
- Версія в `app.main` і `pyproject.toml` — 1.0.0; бейджі тестів — 178 passing.

## [0.4.0] — 2026-11-05

### Додано
- **CSV-імпорт** тим самим майстром, що й xlsx: авто-детект роздільника
  (`,` `;` таб `|`) та кодування (BOM → UTF-8 → CP1251), вікно maping'у,
  fuzzy-пропозиції та валідація типів працюють без змін.
- **Kanban-подоба** за статусом: колонки = стандартні статуси + будь-які
  статуси з даних, drag & drop картки → PATCH статусу (з аудитом).
- **Збережені фільтри** (named views): назва + JSON фільтрів на колекцію;
  dropdown у поданні рядків, застосовується і до таблиці, і до канбану;
  видаляти може автор або адмін.
- **Масові дії (bulk actions)**: чекбокси на рядках → масова зміна статусу
  (`POST /api/rows/bulk`) та масове видалення (тільки адмін,
  `POST /api/rows/bulk-delete`); audit-подія на кожен рядок.
- **Безпека**: паролі — PBKDF2-HMAC-SHA256 (200 000 ітерацій, сіль на
  користувача); сесії мають TTL 24 години (протухлі токени видаляються);
  `POST /api/logout` інвалідує токен. Легасі sha256-хеші v0.3.0 працюють
  і прозоро оновлюються при першому вході.
- `POST /api/logout`, нові ендпоінти фільтрів, smoke-скрипт `scripts/smoke.sh`.

### Змінено
- `db.ensure_admin` / `db.create_user` створюють PBKDF2-хеші замість sha256.

## [0.3.0] — 2026-10

### Додано
- **Розрахункові колонки**: формули виду `=quantity*amount` (безпечний
  evaluator, значення рахуються на льоту), адмін керує формулами.
- **Нагадування по дедлайнах**: email-outbox (`/api/reminders/*`),
  ідемпотентний запуск, реальна відправка через SMTP за конфігурацією.
- **Шаблони колекцій** одним кліком: замовлення / клієнти / інвентар.
- **Багатокористувацьість** з ролями: `admin` (імпорт, аудит, користувачі,
  нагадування) та `worker` (перегляд, редагування рядків, експорт).
