## Чому це існує

Малі бізнеси десятиліттями живуть в Excel — і продовжують жити, бо жоден готовий
інструмент не повторює *їхній* процес:

- **96%** FP&A професіоналів досі працюють в Excel (AFP 2025).
- **72%** SME ведуть фінанси у спредщитах.
- Типові скарги SMB: *"our process is too custom, no tool fits"*, відсутність
  audit trail («хто змінив ціну?!»), файли виду `final_v7_latest_final.xlsx`,
  паніка, коли ops-lead у відпустці і ніхто не знає, як «той самий» файл влаштований.

SheetFlow існує, щоб забрати ці болі: не змушувати людей міняти процес,
а імпортувати ЙОГО — і одразу дати те, чого Excel не має: валідацію типів,
спільну роботу з ролями та незнищуваний журнал «хто/коли/що змінив».

## Наша ідея

**Не змушувати міняти процес — імпортувати ЙОГО.**

1. Завантажуєш свій звичний `.xlsx`.
2. Майстер імпорту **сам пропонує мапінг колонок** (fuzzy match за назвами,
   укр/англ) — ти лише підтверджуєш або виправляєш; рядок-шапка визначається
   автоматично або вибирається вручну.
3. SheetFlow створює колекцію з валідацією типів і структурує хаос.
4. Далі — список з фільтрами, **inline-редагування всіх полів**, **audit log**
   (хто/коли/що змінив), прострочені дедлайни підсвічені червоним,
   CSV-експорт назад у звичний світ.

## Можливості (v0.4.0)

- Імпорт `.xlsx` **і `.csv`** з **fuzzy авто-мапінгом** колонок та **авто-детектом
  рядка-шапки**; для CSV — авто-детект роздільника (`,` `;` таб `|`) і кодування
  (UTF-8/UTF-16 BOM → CP1251).
- **Kanban-подоба** за статусом з drag & drop (перемикач таблиця/канбан).
- **Збережені фільтри** (named views) — швидкий доступ до улюблених зрізів даних.
- **Масові дії**: чекбокси → масова зміна статусу або видалення,
  audit-подія на кожен рядок.
- **Безпека**: паролі в PBKDF2 (соль+200k ітерацій), сесії з TTL 24 год,
  logout.
- **Inline-редагування всіх полів** таблиці (PUT) + audit log на кожну зміну.
- **Розрахункові колонки**: формули виду `=quantity*amount` як derived-поля
  (обмежений безпечний evaluator, значення вважаються на льоту).
- **Нагадування по дедлайнах**: outbox черга email (`/api/reminders/*`),
  ідемпотентний запуск, реальна відправка через SMTP за конфігурацією.
- **Шаблони колекцій** одним кліком: замовлення, клієнти, інвентар.
- **Багатокористувацьість**: роль `admin` (імпорт, аудит, користувачі,
  нагадування, видалення) та `worker` (перегляд, редагування рядків, експорт).

Перший користувач системи автоматично стає адміном.

## Швидкий старт

```bash
git clone https://github.com/<user>/sheetflow.git && cd sheetflow
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload    # http://127.0.0.1:8000
```

**Демо-доступ:** `admin / admin123` (перший користувач = адмін;
змініть пароль перед продакшеном).
